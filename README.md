# readcode

readcode genera "estudios" de repositorios de código (índice de símbolos, explicaciones por archivo, recorridos, grafos y diffs entre commits) y ofrece un visor en el navegador para leerlos. El núcleo en Python nunca llama a un LLM: las explicaciones las redacta un agente y el núcleo las valida y las sirve.
